# 연구비서 Windows 시험판 확인 안내

시험판에 참여해 주셔서 감사합니다. 아래 순서대로 확인한 뒤 결과를 알려 주시면 됩니다.

## 설치

받으신 `research-assistant-0.1.0-x64.exe`는 서명을 받지 않은 시험판입니다. 그래서 실행하면 Windows SmartScreen이 경고 창을 띄웁니다. 창의 `추가 정보`를 누른 다음 `실행`을 누르면 설치가 진행됩니다.

## 처음 실행

주제를 나타내는 영어 키워드를 한두 개 입력하고(예: `protein folding`) `시작하기`를 누릅니다. 약 1분 안에 논문, 저장소, 뉴스 목록이 나타납니다. OpenAlex 키 칸은 비워 두셔도 됩니다.

## 확인할 네 가지

각 항목에 대해 `예` 또는 `아니요`로 알려 주시고, `아니요`이면 화면을 찍어 함께 보내 주십시오.

1. 목록이 나타났습니다.
2. `설정`에서 `알림 테스트`를 누르면 Windows 알림이 나타납니다.
3. 창을 닫아도 앱이 시스템 트레이(시계 근처의 원자 모양 아이콘, `^` 화살표 안에 숨어 있을 수 있음)에 남아 있고, 그 아이콘을 누르면 창이 다시 열립니다.
4. 컴퓨터를 다시 시작하고 로그인한 뒤, 창은 보이지 않지만 앱이 트레이에서 실행 중입니다.

## 종료와 삭제

- 종료: 트레이 아이콘을 오른쪽 클릭하고 `종료`를 누릅니다.
- 삭제: Windows 설정의 `앱`에서 `연구비서`를 찾아 제거합니다.
